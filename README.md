# Louisa Wi-Fi for Windows

到不同的路易莎門市時，Wi-Fi 名稱通常都叫 `LouisaCoffee`，但密碼可能不同。這個工具讓你搜尋所在門市、嘗試該店的電話衍生密碼，並記住成功連上的路由器，減少換店時重新設定的麻煩。

[下載最新版安裝程式或 ZIP](https://github.com/05zhi/louisa-wifi-windows/releases)

## 可以做什麼？

- 用店名、地址、電話或縣市找門市，內建資料離線也能查。
- 手動選店連線，或輸入店內提供的 Wi-Fi 密碼。
- 記住成功連過的路由器，下次優先嘗試。
- 選擇使用定位，尋找五公里內最近三家門市。
- 在系統匣常駐，查看 Wi-Fi 狀態與每天在門市的連線時間。
- 檢查更新，下載前徵求同意並核對檔案校驗碼。

## 安裝與更新

目前支援 Windows 11 x64，內含 .NET，不必另裝 runtime。

| 下載檔案 | 使用方式 |
| --- | --- |
| `LouisaWiFi-Setup-x64.exe` | 執行安裝程式，完成後從開始功能表開啟。 |
| `LouisaWiFi-win-x64.zip` | 解壓縮到固定資料夾，執行其中的 `LouisaWiFi.exe`。不要直接從 ZIP 內執行。 |
| `SHA256SUMS.txt` | 供核對下載檔案的 SHA-256 校驗碼。 |

更新前，請先到「設定與說明」按「完全結束程式」，或在系統匣圖示按右鍵選「結束」。按視窗右上角的 × 只會縮到系統匣，程式仍在執行。

安裝版可執行新版安裝程式更新；ZIP 版請在舊版完全結束後，解壓新版並執行。原本的設定與連線記憶保存在另一個本機資料夾，不會因換程式資料夾而消失。也可以從程式的「檢查更新」下載安裝版。

程式尚未簽章。請核對下載來源為本專案；不確定 Windows 警告的原因時，先不要執行。

## 使用說明

### 第一次到店，手動選店連線

1. 開啟「尋找門市」，輸入店名、地址或電話，也可選擇縣市。
2. 點選清單中的門市，核對地址，避免選到同名分店。
3. 按「連線到這家店」。程式會依序嘗試候選密碼，畫面上會顯示進度。
4. 成功後會顯示已連上門市，並記住實際連上的路由器。
5. 若 Wi-Fi 已連線但仍無法上網，開啟瀏覽器確認是否需要完成門市驗證頁。

02 區碼，以及 04 區碼搭配八位電話的門市，會先嘗試不含區碼的八位電話。電話衍生密碼只是候選，不能保證適用每家店。

已連上其他 Wi-Fi 或手機熱點時，程式會保留目前連線。如果要改連門市，請先在 Windows 中斷原有 Wi-Fi，再回來按連線。按「取消連線」會停止本次後續嘗試。

搜尋不到時，可按「清除篩選」清除關鍵字、縣市、附近門市及「只顯示連過的門市」條件。

### 店內密碼與電話不同

1. 選好門市，展開「店內密碼不同？使用自訂密碼」。
2. 勾選「改用店內提供的密碼」，輸入密碼。
3. 按「連線到這家店」。密碼需為 8 至 63 個可列印英數字或符號。
4. 若希望下次選這家店時仍帶入密碼，按「記住此店密碼」。密碼會加密保存在本機。

「忘記自訂密碼」會移除此店手動儲存的密碼，恢復使用電話衍生候選。成功連線建立的路由器記憶是另一份資料；若要連同它一起移除，請使用設定頁的「清除本機資料」。

### 定位與附近門市

定位有兩個不同的開關：

| 設定 | 控制什麼？ |
| --- | --- |
| 程式內「允許本程式用定位尋找門市」 | 是否用你的位置尋找附近門市。預設關閉，可隨時關閉。 |
| Windows 的定位權限 | Windows 是否允許程式取得位置，以及部分 Wi-Fi 掃描資訊。程式不會替你更改它。 |

使用附近門市：

1. 在「尋找門市」按「尋找附近門市」。若尚未啟用，程式會帶你到設定頁。
2. 按「啟用定位並尋找」。已啟用時，按「尋找附近門市」即可。
3. 若出現權限被拒或系統定位關閉，按「開啟 Windows 定位權限」。
4. 在 Windows 的「隱私權與安全性 → 位置」確認「位置服務」及適用的應用程式／桌面應用程式存取權限。各 Windows 版本顯示名稱可能不同。
5. 回到程式查看結果，必要時按「重新檢查定位」，再尋找附近門市。

狀態顯示「目前無法取得足夠準確的位置」時，不一定是權限問題。請稍後重試，或改用店名搜尋。五公里內沒有資料時，按「清除篩選」即可搜尋所有門市。

不開啟程式定位也能手動選店，但部分 Windows 版本仍要求定位權限，才能掃描 Wi-Fi。詳見 [Microsoft 的 Wi-Fi 定位權限說明](https://learn.microsoft.com/en-us/windows/win32/nativewifi/wi-fi-access-location-changes)。

### 自動連線與登入啟動

- 「沒有 Wi-Fi 連線時，自動嘗試連線」預設關閉。開啟後，優先使用已記住的門市路由器；有有效定位時，也會嘗試附近門市。
- 第一次到店，建議先手動選店完成一次連線。單純儲存自訂密碼，不代表已辨識並記住附近路由器。
- 自動嘗試失敗後會暫停十分鐘，仍可手動選店重試。
- Windows 曾拒絕 Wi-Fi 權限時，修正權限後可先手動重試；若要恢復自動嘗試，關閉再開啟自動連線。
- 「登入 Windows 時啟動」控制下次登入是否啟動程式，不會同時開啟自動連線或定位。

### 連線統計與關閉程式

「連線統計」可依年份、月份與門市查看使用時間。只計算確認連上 `LouisaCoffee` 的時間，睡眠時間不累計；連上 Wi-Fi 不代表一定能存取網際網路。

關閉視窗後，程式仍留在右下角系統匣，圖示可能藏在「顯示隱藏的圖示」內。雙擊圖示可開啟視窗；要完全離開，請選「結束」，或到設定頁按「完全結束程式」。

## 常見問題

| 情況 | 可以怎麼做？ |
| --- | --- |
| 連線按鈕是灰色 | 先點選一筆門市；連線進行中會暫時停用。 |
| 找不到門市 | 按「清除篩選」，再輸入較短的店名或電話。 |
| 附近找不到 LouisaCoffee | 確認已在門市、Windows Wi-Fi 已開啟，且網路名稱正確。 |
| Wi-Fi 存取被拒 | 到設定頁開啟 Windows 定位權限，調整後再手動嘗試。 |
| 密碼候選都失敗 | 核對門市地址，並向門市確認密碼，再使用自訂密碼。 |
| 連上 Wi-Fi 但不能上網 | 開啟瀏覽器檢查驗證頁，也可能是門市網路本身未連上網際網路。 |
| 資料夾無法刪除或更新 | 先「完全結束程式」；只按 × 並不會退出。 |
| 仍有問題 | 打開「診斷資訊」，提供程式版本、Windows 版本及畫面顯示的錯誤代碼。請勿公開密碼、精確位置或完整路由器識別碼。 |

## 隱私與移除

設定、密碼、連線記憶與統計存放於 `%LOCALAPPDATA%\LouisaWiFi`，不主動上傳。記住的密碼使用 Windows 目前使用者的 DPAPI 加密；定位座標不寫入檔案。診斷紀錄只包含狀態與錯誤代碼。更新檢查會連線至本專案的 GitHub Release。

「清除本機資料」會要求確認，並移除設定、路由器記憶、自訂密碼及使用統計。解除安裝會移除程式、捷徑與登入啟動項目，但保留本機資料；如要全部移除，請先在程式內清除。ZIP 使用者刪除程式前，請先關閉登入啟動並完全結束程式。

## 支援範圍

目前為 Windows 11 x64 預覽版，支援 WPA2-Personal／AES。已有單一實際門市連線驗證，其他門市、網卡與定位權限情境仍可能有差異。Windows 10、ARM64、WPA3-only 及企業驗證尚未支援或驗證。

## 開發

需要 Windows、`global.json` 指定的 .NET SDK、Python 3.11+ 與 PowerShell。

```powershell
./scripts/build.ps1
./scripts/package.ps1
```

第一個指令會驗證門市資料、建置並執行核心、Windows 與隔離 UI 流程測試；第二個會產生安裝程式與 ZIP。封裝工具使用固定版本並驗證下載完整性。硬體測試項目見 [HARDWARE-TESTS.md](docs/HARDWARE-TESTS.md)。
